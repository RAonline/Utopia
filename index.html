Vercel Deployment Architecture

How StreamPulse handles storage on static hosting

Client-Side Persistence (IndexedDB)

StreamPulse stores full binary video file blobs inside your browser's IndexedDB engine. This eliminates the 5MB `localStorage` limit and allows uploading large MP4/WebM videos directly on Vercel without server endpoints.

Multi-User Scaling (Vercel Blob / Cloudinary)

For global cross-device video sharing, connect Vercel Blob or AWS S3 in `handleVideoUpload()`:

// Example Cloud API integration
const blob = await vercelBlob.put(file.name, file, { access: 'public' });
videoRecord.videoUrl = blob.url;
